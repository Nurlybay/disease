# Routine clinical panels

The 12 built-in cases now expose a fixed CBC with differential and ESR, and a separate routine urinalysis. Values are fictional teaching data, not generated by the chat model. `tools/enrich-clinical-panels.js` is an idempotent generator of marked sections at the end of each protected case source. Original case scripts and scoring functions remain intact.

Existing Hb, WBC, platelet, differential and ESR findings are preserved where specified. Missing CBC metrics are fixed synthetic values. RBC indices and absolute differential counts are calculated consistently; differential percentages total 100. COPD eosinophils remain 0.120 ×10⁹/L (120/µL). Combined inflammatory/renal orders retain their original CRP, potassium and creatinine results below the CBC. Chemistry, lipids, troponin and urine albumin/creatinine remain separate investigations; these are not components of routine CBC or urinalysis.

Urinalysis uses a fixed normal teaching specimen in each case because no urinary abnormality was defined in the original scenarios. This does not establish normal renal function or exclude albuminuria; the separate albumin/creatinine test is preserved. New available investigations have zero grading weight and do not require students to order them. No automatic abnormal-value highlighting is applied to laboratory tables, including independent mode.

The report lists the reference intervals of a simulated adult laboratory, including sex-specific Hb/RBC/Hct ranges. Intervals and methods vary by actual laboratory. CBC includes Hb, RBC, Hct, MCV, MCH, MCHC, RDW-CV, WBC, five differential counts in both percent and absolute units, platelets, MPV, and ESR. ESR is an explicitly named additional component, not an implicit part of every CBC. Urinalysis includes appearance, dipstick chemistry and sediment microscopy; absence on microscopy is not a urine culture result.

Clinical structure references:
- [MedlinePlus: Complete Blood Count](https://medlineplus.gov/lab-tests/complete-blood-count-cbc/)
- [MedlinePlus: Urinalysis](https://medlineplus.gov/ency/article/003579.htm)
- [Mayo Clinic: Complete blood count](https://www.mayoclinic.org/tests-procedures/complete-blood-count/about/pac-20384919)

Validation: `node tools/test-clinical-panels.js`, identity/routing tests and existing cardiology/new-case/practice tests. Protect generated case sources through `python3 tools/build-learning-content.py` and deploy the learning-content function before publishing the frontend.

## Heart and sputum extension

`tools/heart-sputum-data.js` adds fixed, case-specific heart descriptions (S1/S2, rhythm, accentuation/splitting, extra sounds and murmurs) while preserving the original arrhythmia, pulse deficit, gallop and pericardial rub findings. These are scripted findings, not proof that a named disease always produces that auscultatory picture.

Routine sputum examination now has a separate 14-row macroscopic/microscopic report. Culture/susceptibility remains a separate order. Existing H. influenzae and mucoid P. aeruginosa culture results and antibiotic susceptibilities are preserved. New sample volumes refer to the submitted aliquot, not daily sputum production. For cases without an available specimen, the report explicitly marks the examination as not performed rather than giving a false negative. Stable chronic bronchitis retains its original unperformed culture. Qualitative microscopy does not use invented numeric normal ranges. AFB testing remains a separate investigation.

References: [Merck: Cardiac auscultation](https://www.merckmanuals.com/professional/cardiovascular-disorders/approach-to-the-cardiac-patient/cardiac-auscultation), [MedlinePlus: Sputum culture](https://medlineplus.gov/lab-tests/sputum-culture/), [MedlinePlus: AFB tests](https://medlineplus.gov/lab-tests/acid-fast-bacillus-afb-tests/).

## Interview coverage

The patient response includes a private structured coverage list with existing passport/interview IDs and exact question/answer evidence. Server and client validate the IDs and quotations; exams/treatments cannot be credited through this channel. Known refusals and unsupported evidence are excluded. One compound question can credit several topics. The visible/spoken output remains the plain patient reply. Old plain-text responses use the existing keywords and explicit alternative phrases as a fallback. Structured empty coverage is respected. Matched IDs and actual dialogue survive export/import so teachers can review automatic matching. AI matching is a teaching aid and can still make semantic errors.

Tests: `test-question-coverage.js`, `test-heart-sputum.js`, server/client chat tests, and previous panel/scoring tests. Generator preserves helper functions using an explicit `END PATIENT CARDS` marker.
