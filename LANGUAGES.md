# Русский и казахский

На всех четырёх страницах есть выбор «Русский / Қазақша». Выбор сохраняется
в браузере и передаётся в ссылках через `?lang=ru` / `?lang=kk`.
Смена языка не перезагружает приём и не сбрасывает выполненные действия.
Исходный текст пользовательских заметок и история свободного диалога сохраняются.

## Что переводится

Интерфейс, встроенные случаи всех 12 пациентов, результаты обследований,
разбор и критерии, раздел преподавателя, конструктор и медиапрактикум.
Локальный каталог не требует переводчика во время работы сайта. ID действий,
числа, алгоритмы и баллы одинаковы в обоих языках. Произвольные тексты
пользовательских случаев не переводятся автоматически.

Казахские команды осмотра и измерений сопоставляются с существующими действиями.
Неизвестные формулировки идут в диалог, а не исполняются как назначения.
Например: «өкпені тыңдау», «қан қысымын өлшеу», «жөтеліңізші»,
«жедел жәрдем шақыру». Вопросы к ИИ получают выбранный язык через сервер;
модель по-прежнему обязана придерживаться фактов конкретного пациента.

## Голос

268 сценарных реплик доступны в локальных казахских MP3: Aigul для женщин,
Daulet для мужчин. Их можно слушать и без сети после загрузки файлов.
Русские исходные записи сохранены; девять реплик с формами «покашлял» и т. п.
перезаписаны с явным ударением. Для синтеза используются «прока́шляйте»,
«пока́шляю» и соответствующие формы. Видимый текст не меняется.
Наличие ударения в тексте TTS не гарантирует безошибочное произношение каждого
медицинского термина; словарь можно расширять по результатам прослушивания.

Свободные ответы ИИ озвучиваются системным голосом выбранного языка, если
он есть в браузере. Если казахского голоса нет, остаётся текст: русская озвучка
не подставляется. Распознавание получает `ru-RU` или `kk-KZ`, но фактическая
поддержка зависит от браузера. Диагностические записи сердца и лёгких
не переводятся и не заменяются синтезированными звуками.

## Происхождение и проверка перевода

Черновик Google Translate подготовлен с разрешения владельца проекта.
В `site/locales/kk-overrides.json` хранятся вычитанные фразы и исправления
терминов, клинических смыслов и чисел. Полной редакторской/клинической вычитки
всего казахского пакета пока не было; перед использованием для итоговой
аттестации она нужна. Тесты проверяют покрытие каталога, сохранность чисел,
соответствие аудио текущему переводу и распознавание команд.
Ни ключи, ни переписка пользователя переводчику не передавались.

## Обновление

Из корня проекта:

```sh
npm ci --prefix tools/localization
node tools/extract-localization.js
python3 tools/prepare-locale.py
# Сеть: только при подготовке черновика перевода с разрешения владельца.
python3 tools/translate-kazakh.py
# Сначала отредактировать kk-overrides.json, затем:
python3 tools/build-locales.py
tools/.venv/bin/python tools/make-localized-voice.py ru
tools/.venv/bin/python tools/make-localized-voice.py kk
node tools/test-locales.js
node tools/test-kazakh.js
```

Новые реплики Microsoft Edge TTS генерируются только при разработке с
разрешения владельца. В готовом сайте записанные реплики — обычные MP3.

Голоса и языки Microsoft: https://learn.microsoft.com/en-us/azure/ai-services/speech-service/language-support
Орфографическая форма «прока́шлять(ся)»: https://gramota.ru/storage/public/normdicts/orfograficheskij_slovar.pdf
