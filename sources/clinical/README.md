Проверено 7 сентября 2026 года. Это открытые самостоятельные учебные примеры,
не записи вымышленных пациентов. Авторская разметка проверена по источнику;
независимая клиническая редактура преподавателем ещё не выполнена.

Разметка рамками для каждого изображения предоставляется под той же
лицензией CC BY-SA, что и соответствующее изображение. Авторы оригиналов
не подтверждали и не одобряли этот тренажёр. Имена авторов, ссылки на
источники, лицензии и описание изменений показаны прямо рядом с заданиями.

Исходные OGG сохранены здесь. `manifest.json` содержит контрольные суммы,
длительности, источник и ограничения каждого примера. Диагнозы отражают
разметку автора источника; точные ЧСС и результаты виртуального пациента
не подгонялись под стороннюю запись. Две записи ФП не синхронизированы.

Не включены: MurmurO.ogg (это шум сонной артерии, а не шум клапана сердца),
записи трения перикарда и III тона с неподтверждёнными правами. Они не
заменены синтетическими шумами. Для этих признаков пока остаётся текст.

Перекодирование звука:

```
ffmpeg -i heart-01.ogg -map_metadata -1 -c:a libmp3lame -q:a 2 ../../site/media/clinical/heart-01.mp3
ffmpeg -i heart-02.ogg -map_metadata -1 -c:a libmp3lame -q:a 2 ../../site/media/clinical/heart-02.mp3
```

## Визуальные персонажи и голоса

`site/media/patients/*.png` — четыре ИИ-портрета вымышленных персонажей.
Созданы встроенным инструментом image_gen. Полные запросы и соответствие
файлов — в `portrait-prompts.json`. На сайте портреты явно обозначены
как иллюстрации, не предназначенные для выявления медицинских признаков.
Движение — включаемая CSS-анимация изображения, не видео и не имитация
дыхательного паттерна; `prefers-reduced-motion` отключает анимацию.

Реплики новых пациентов созданы скриптом `tools/make-cardiology-voice.py`
через edge-tts, как существующая озвучка проекта. Голос DmitryNeural:
Сапаров −5%, −5 Hz; Искаков −8%, −12 Hz; Нургалиев −12%, −25 Hz;
Алимов 0%, +10 Hz. Это синтез вымышленных реплик, не клонирование голоса.
Сервис получает только текст; сайт проигрывает сохранённые MP3 без сети.
Путь MP3 определяется хешем текста и профиля; для изменения текста нужно
перегенерировать озвучку. Скрипт обновляет поле audio только после успешной
генерации и проверки длительности. Полноценное индивидуальное видео и
синхронизация губ не реализованы.
